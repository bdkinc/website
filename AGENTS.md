# AGENTS.md

## Project Overview
This is the corporate presence for an MSP/CSP/Software Provider, built with **Astro** and **React**.
Performance is critical: ship static HTML by default, hydrate only when necessary.

## Quick Start
- **Package Manager:** `npm`
- **Builds:** Do **NOT** run full builds (`npm run build`) without explicit user instruction.
- **Branding:** Adhere strictly to rules in `guides/`.
